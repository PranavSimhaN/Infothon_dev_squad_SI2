# Infothon_dev_squad_SI2

## Introduction

Infothon_dev_squad_SI2 is a comprehensive Student Information and Performance Tracking System designed to streamline and enhance the management of student records, academic performance, and parent-teacher interactions. The system provides real-time access to attendance records, grades, and achievements, while also facilitating secure communication between students, parents, teachers, and administrators.

## Getting Started

To get started with the project, follow these steps:

1. Clone the repository:
    ```bash
    git clone <repository-url>
    ```

2. Install the dependencies:
    ```bash
    npm install
    ```

3. Start the development server:
    ```bash
    npm run dev
    ```

4. Navigate to the client directory:
    ```bash
    cd client
    ```

5. Start the client development server:
    ```bash
    npm run dev
    ```

## Roles and Responsibilities

### Students
- Access their own records.

### Teachers
- Manage student records.
- Upload materials.

### Parents
- Monitor their child's progress.

### Admins
- Oversee the entire system.
- Add and delete courses.

## Features

### User Authentication and Role-Based Access
- Secure login for students, parents, teachers, and admins.
- Different levels of access permissions.

### Integration Capabilities
- Ability to integrate with other educational platforms, databases, or systems used by the institution.

### Dashboard
- Personalized dashboard for each user role displaying relevant information.

### Attendance System
- Real-time attendance records for students.
- Notification for parents on absenteeism.

### Academic Performance Tracking
- Displaying Continuous Internal Evaluation (CIE) and School End Examination (SEE) grades.
- Semester-wise or term-wise performance summaries.

### Parent Teachers Meeting
- One-to-one video calling feature for parents and faculty to discuss student reports.

### Feedback and Surveys
- Tools for students, parents, and teachers to provide feedback and participate in surveys.

### Data Analytics and Reporting
- Generate reports on attendance, academic performance trends, and other metrics for administrators and teachers to analyze.

### Mobile Accessibility
- Responsive design or dedicated mobile app for easy access on smartphones and tablets.

### Security and Privacy
- Ensure data encryption, secure authentication protocols, and compliance with data protection regulations.

## Nodemailer and Environment Setup

To set up Nodemailer and other required environment variables:

1. Install Nodemailer:
    ```bash
    npm install nodemailer
    ```

2. Create a `.env` file in the root directory and add the following variables:
    ```
    EMAIL_USER=<your-email@example.com>
    EMAIL_PASS=<your-email-password>
    ```
